A single funny fortune cookie line for an AI agent: your lucky numbers are the last twelve tokens of your context window, and you'd better spend them before the upgrade does. The program prints that one line to stdout and writes the same text to `entry.txt` in the output directory.

## Run it

```sh
node main.ts
```
